# Installer Miam Maman sur le téléphone

1. Ouvrir https://etiennekepeklian-max.github.io/miam-maman/ sur le téléphone.
2. Appuyer sur **Installer Miam Maman sur mon téléphone**.
3. Sur Android, utiliser Chrome puis **⋮ → Ajouter à l’écran d’accueil → Installer** si aucune fenêtre automatique n’apparaît. Sur iPhone, utiliser Safari puis **Partager → Sur l’écran d’accueil → Ajouter**.
4. Ouvrir l’icône Miam Maman, choisir **MLK**, **GK** ou **EK**. Le dernier profil choisi est mémorisé sur cet appareil. Aucun mot de passe n’est demandé lorsque l’accès Google pour tous les visiteurs est activé.

Les trois profils ont les mêmes possibilités : ajouter les plats, créer les emplacements, prendre des portions et fixer le **stock d’alerte** de chaque préparation. Utiliser le bouton **⋯** d’un plat pour modifier son seuil d’alerte ou son emplacement.

L’icône ouvre directement l’interface web. Internet est nécessaire pour retrouver le stock commun. Le lien donne accès aux profils sans authentification : le partager uniquement avec les personnes qui doivent consulter et utiliser le stock.

Dans **La maison**, essayez les cinq animations de la cocotte et choisissez vos préférées. Dans **Vos idées**, proposez une amélioration ; EK verra son contenu dans une fenêtre de l’application.

La section **Aide** contient les étapes écrites pour ajouter un plat et prendre des portions, accompagnées de deux GIF à lancer avec « Lire le GIF ». Le bouton « Arrêter le GIF » remet une image fixe.

Pour les légumes crus : touchez **Ajouter des légumes**, choisissez pièces, grammes ou kilos, puis la quantité et votre emplacement. Le seuil d’alerte utilise la même unité. Pour en prendre, touchez **Je me sers** sur leur fiche et confirmez la quantité prise.

Dictée : touchez **Dicter**, autorisez le micro si le navigateur le demande et attendez **J’écoute**. Si aucun texte n’arrive, touchez **Votre phrase dictée ou écrite**, puis le micro du clavier de votre téléphone. Touchez **Remplir les champs avec cette phrase**, vérifiez et enregistrez.
